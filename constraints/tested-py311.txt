# Install with:
#     python -m pip install -e ".[dev]" -c constraints/tested-py311.txt
#
# WHY THIS FILE EXISTS
# --------------------
# Unconstrained resolution has installed NumPy 2.5.x together with OpenCV
# 5.0.x. That combination aborted the interpreter on `import cv2` with exit
# code 135 (SIGBUS) before a single test could run — a failure that looks like
# a broken repository but is a dependency-resolution problem.
#
# The pins below are the exact versions this project's test suite was run
# against. They are a floor for reproducibility, not a claim that nothing else
# works: pyproject.toml carries deliberately conservative ranges
# (numpy>=1.26,<2.3, opencv-python-headless>=4.9,<5) and this file pins inside
# them.
#
# Compatibility with NumPy 2.3+ or OpenCV 5.x is UNTESTED and therefore not
# claimed. When you are ready to move the ceiling: raise the bound in
# pyproject.toml, update these pins, and re-run the full suite on Python 3.11
# on Windows 11 before relying on it.
